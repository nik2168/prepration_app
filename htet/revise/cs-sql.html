Most asked: which command is DDL or DML (4 times since 2020), VIEW = virtual table (3), UPDATE changes values (2), DROP vs DELETE (2). Also asked: ALTER adds a column, HAVING vs WHERE, ORDER BY, aggregate functions.

Command groups

GroupCommandsWhat it changes
DDL: Data DefinitionCREATE, ALTER, DROP, TRUNCATE, RENAMEThe structure (schema) of tables
DML: Data ManipulationSELECT, INSERT, UPDATE, DELETEThe rows (data) inside tables
DCL: Data ControlGRANT, REVOKEWho may do what
TCL: Transaction ControlCOMMIT, ROLLBACK, SAVEPOINTSaving or undoing changes
  • "Query and modification commands" (query, insert, delete) are DML. "Creating the structure of relations" is DDL.
  • UPDATE is not DDL (it is DML). TRUNCATE is DDL.
  • The result of a SELECT is always a table (a relation).

Look-alike commands

TaskCommand
Add, remove or change a columnALTER TABLE t ADD col INT;
Change values in rowsUPDATE t SET marks = 90 WHERE id = 5;
Remove rows but keep the tableDELETE FROM t; (can use WHERE, can be rolled back)
Remove all rows fast, keep the structureTRUNCATE TABLE t; (no WHERE)
Remove the table and its dataDROP TABLE t;

2022 Q134 pattern: "keep R but empty it" → DELETE FROM R; "remove R completely" → DROP TABLE R.

SELECT and its clauses

SELECT dept, COUNT(*)      -- columns
FROM   staff               -- table
WHERE  salary > 30000      -- filters rows, before grouping
GROUP BY dept              -- makes groups
HAVING COUNT(*) > 5        -- filters groups, after grouping
ORDER BY dept DESC;        -- sorts (ASC is the default)
  • Sorting uses ORDER BY (not SORT BY).
  • HAVING is like WHERE, but it works on groups and can use aggregate functions. WHERE cannot use aggregates.
  • Aggregate functions: COUNT, SUM, AVG, MAX, MIN. COMPUTE is not one. COUNT(*) counts every row; COUNT(col) skips NULLs.
  • Other clauses that get asked: DISTINCT, BETWEEN, IN, LIKE (% = any characters, _ = one character), IS NULL.

Views and nested queries

  • A VIEW is a virtual table made from other tables by a stored query: CREATE VIEW v AS SELECT …; It stores no data of its own.
  • A nested query (subquery) is a complete SELECT-FROM-WHERE block inside another query: … WHERE marks > (SELECT AVG(marks) FROM t).

Relational algebra links

  • Select (σ) picks rows that satisfy a selection condition; Project (π) picks columns.
  • Set operations: (R − S) and (S − R) never share a tuple, so (R − S) ∩ (S − R) = φ.

Constraints and keys in SQL

  • PRIMARY KEY (unique + not null), UNIQUE, NOT NULL, DEFAULT, CHECK, FOREIGN KEY (REFERENCES another table).
