सबसे ज़्यादा पूछा गया: 2020-2024 में हर साल 1 प्रश्न (कुल 5): संधि-विच्छेद की जाँच (2021, 2023), संधि का प्रकार पहचानना (2020 व्यंजन, 2022 विसर्ग, 2024 यण्/दीर्घ/व्यंजन/विसर्ग मिश्रित)। तीनों भेदों के उदाहरण याद रखें।

स्वर संधि

दीर्घ

अ/आ+अ/आ = आ; इ/ई+इ/ई = ई; उ/ऊ+उ/ऊ = ऊ

विद्या + आलय = विद्यालय

लघु + ऊर्मि = लघूर्मि

गुण

अ/आ + इ/ई = ए; + उ/ऊ = ओ; + ऋ = अर्

महा + ईश = महेश

चंद्र + उदय = चंद्रोदय

वृद्धि

अ/आ + ए/ऐ = ऐ; + ओ/औ = औ

सदा + एव = सदैव

परम + औषध = परमौषध

यण्

इ/ई → य्, उ/ऊ → व्, ऋ → र् (बाद में असमान स्वर)

यदि + अपि = यद्यपि

सु + आगत = स्वागत

अयादि

ए → अय्, ऐ → आय्, ओ → अव्, औ → आव्

ने + अन = नयन

गै + अन = गायन

नौ + इक = नाविक

ध्यान दें: गुरु के अपवाद: अक्ष+ऊहिनी = अक्षौहिणी, प्र+ऊढ = प्रौढ (पृ. ७५)। दैत्य+अरि = दैत्यारि (दीर्घ, यण् नहीं)। गति+अनुसार = गत्यनुसार, अग्नि+आशय = अग्न्याशय (यण्)। गुरु+उपदेश = गुरूपदेश (दीर्घ, 'गुरोपदेश' गलत)। अभि+इप्सा = अभीप्सा। पर+उपदेश = परोपदेश (गुण, विसर्ग नहीं)। गुरु (पृ. ७४-७६) में गुण, वृद्धि, यण् नाम हैं; 'अयादि' नाम नहीं, नियम (६५) है। ए/ओ + अ में अ का लोप (ते+अपि = तेऽपि) हिंदी में प्रचलित नहीं (पृ. ७७)। यण् में पहले स्वर वाला वर्ण आधा हो जाता है।

व्यंजन संधि

वर्ग का पहला → तीसरा

बाद में स्वर या घोष वर्ण

वाक् + ईश = वागीश

जगत् + ईश = जगदीश

दिक् + गज = दिग्गज

पहला → पाँचवाँ

बाद में न/म

वाक् + मय = वाङ्मय

जगत् + नाथ = जगन्नाथ

त् संबंधी

उत् + चारण = उच्चारण

उत् + लास = उल्लास

उत् + हार = उद्धार

सत् + शास्त्र = सच्छास्त्र

म् संबंधी

म् + वर्ग का वर्ण = अनुस्वार/पंचम; म् + य र ल व श ष स ह = अनुस्वार

सम् + पूर्ण = संपूर्ण

अपवाद: सम् + राज = सम्राज

सम् + योग = संयोग

छ संबंधी

स्वर के बाद छ → च्छ

वि + छेद = विच्छेद

परि + छेद = परिच्छेद

स → ष, न → ण

अभि + सेक = अभिषेक

राम + अयन = रामायण

नि + सिद्ध = निषिद्ध

अपवाद: वि + स्मरण = विस्मरण

विसर्ग संधि

अः + घोष → ओ

मनः + हर = मनोहर

वयः + वृद्ध = वयोवृद्ध

अधः + गति = अधोगति

इः/उः + घोष → र्

निः + आधार = निराधार

दुः + उपयोग = दुरुपयोग

र् के आगे र्: पहला र् लुप्त, स्वर दीर्घ

निः + रोग = नीरोग

च/छ → श्; ट/ठ → ष्; त/थ → स्

निः + चल = निश्चल

धनुः + टंकार = धनुष्टंकार

इः/उः + क ख प फ → ष्

निः + कपट = निष्कपट

दुः + कर्म = दुष्कर्म

अपवाद: दुः + ख = दुःख

विसर्ग बना रहता है

अः + क ख प फ: विसर्ग में विकार नहीं

प्रातः + काल = प्रातःकाल

अः + अ → ओऽ

प्रथमः + अध्याय = प्रथमोऽध्याय

मनः + अनुसार = मनोऽनुसार

ध्यान दें (2020 की कुंजी संदिग्ध): गुरु (पृ. ८१): अंत्य स् विसर्ग बन जाता है (निस्+गुण → निः+गुण → निर्गुण), इसलिए तिरस्+हित → तिरोहित और वयोवृद्ध विसर्ग संधि हैं। वागीश, चिदाभास (चित्+आभास), तदर्थ (तत्+अर्थ) व्यंजन संधि हैं (त्+स्वर → द्, पृ. ७७)। युधि+स्थिर = युधिष्ठिर में इ के बाद स → ष (पृ. ७८); गुरु इसे अलुक् समास का उदाहरण भी गिनते हैं (पृ. ४७०)। पहचान: पहला पद व्यंजन पर समाप्त (वाक्, जगत्, सम्) = व्यंजन; पहला पद विसर्ग (ः) से समाप्त = विसर्ग; दोनों ओर स्वर = स्वर संधि।
संधि-विच्छेद जाँच: कुशासन = कुश+आसन (कुश+असन गलत); वार्तालाप = वार्ता+आलाप; जानकीश = जानकी+ईश (जनक+ईश गलत)। जानकी+ईश: ई+ई = ई (पृ. ७४)।
प्रश्न: सही संधि है: (A) सम्+तोष = सन्तोष/संतोष (B) महा+ऋषि = महारिषि (C) नौ+इक = नौइक (D) निः+कर = निःकर

उत्तर: (A) म् + स्पर्श = अनुस्वार या वर्ग का पंचम (पृ. ७८)। महा+ऋषि = महर्षि; नौ+इक = नाविक; निः+कर = निष्कर।

प्रश्न: 'सदैव' में कौन-सी संधि है? (A) दीर्घ (B) गुण (C) वृद्धि (D) यण्

उत्तर: (C) सदा+एव, आ+ए = ऐ।

प्रश्न: विसर्ग संधि का उदाहरण है: (A) उद्धार (B) मनोहर (C) रामायण (D) अत्यंत

उत्तर: (B) मनः+हर (अः + घोष = ओ, पृ. ८०)।

प्रश्न: 'गायन' का संधि-विच्छेद: (A) गा+यन (B) गो+अन (C) गै+अन (D) गौ+अन

उत्तर: (C) ऐ+अ = आय् (पृ. ७६)।

प्रश्न: 'दुर्जन' = (A) दुः+जन (B) दुर+जन (C) दू+जन (D) दुष्+जन

उत्तर: (A) उः + घोष (ज) = र्।
